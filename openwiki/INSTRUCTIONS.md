# Contributor documentation instructions

Explain how contributors maintain this framework: scripts, contract enforcement,
view generation, skills, testing, releases and maintenance procedures. Cite the
repository sources used for each explanation and distinguish enforced behavior
from intended behavior and limitations.

Governed Org and Bounded Context facts belong in documents and generated views.
Link to the relevant view; never repeat a system identifier or fact outside that
link, including in hidden claim records. A generated view wins if this wiki and
a view disagree. Describe the example organizations as fictional.

Never include personal identities, machine paths, credential values, credential
references, or Individual-document content. Do not generate examples from local
configuration. Do not configure LangSmith, integrations, schedules or telemetry.
Only wiki content is generated; root agent instructions retain their handwritten
prefix and the one OpenWiki-managed block.

Do not copy plans, experiments, research, change proposals or test fixtures into
wiki pages. Document accepted repository behavior, with links to maintained
sources instead of a second statement of governed content. The ignore file is
an input selection aid, not a filesystem or network security boundary.

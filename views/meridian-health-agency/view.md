### Meridian Issue Tracker

- Identifier: `issue-tracker`
- Kind: web-app
- Status: active
- Maintainer: `meridian-delivery-tools` (alias)
- Source: `meridian-health-agency@1`

#### Interface `web`

- Status: active
- Type: web
- Network: internal
- URLs:
  - `https://tracker.meridian.invalid/`
- Auth: sso
- Environment variables: none.
- Limitations:
  - Saved filters belong to the person who saved them, so a link to one opens empty for everybody else.

#### Interface `rest`

- Status: active
- Type: rest
- Network: internal
- URLs:
  - `https://tracker.meridian.invalid/api/v2`
- Auth: api-key
- Environment variables:
  - `MERIDIAN_TRACKER_TOKEN` — A personal token the tracker issues; it carries the caller's own permissions and no more.
- Access check: `https://tracker.meridian.invalid/api/v2/self` — A 200 response naming the calling account and the projects it can read.
- Limitations:
  - The API returns at most 100 issues per page and offers no total, so a caller cannot tell a full page from the last one without asking for the next.
  - Attachments are not readable through this interface; the web interface is the only way to open one.

- Auth: none
- Environment variables: none.
- Access check: `https://rates.meridian.invalid/public/v1/schedules` — A 200 response listing the published rate schedules and the period each covers.

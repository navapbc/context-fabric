# Repurposing checklist (human-only)

`navapbc/agentic-workspace` used to hold the Agentic Workspace Starter Kit. This framework takes over that repository, which **stays public under Apache-2.0** (see `LICENSE` and `NOTICE`). The steps below are the ones **no agent may perform on its own**: they push history for the first time, change repository settings, or cut a Release. One of them -- cutting a release -- gained a scripted path in U7 that a person still has to confirm by name; the row says so and the baseline test holds that path to its refusals.

## How to run this

- Execute the rows **top to bottom**. Stop at the first gate that does not hold or the first proof that does not come back as written.
- Fill in the Proof cell's result and the date as you go. A row is not closed until its proof is recorded here.
- **Rows 0-4 close before U2 opens.** OpenSpec is the first thing that writes framework-shaped content, and it should not do that while there is no remote at all.
- **Rows 2 and 3 are withdrawn.** The product owner decided (2026-09-25) to keep `navapbc/agentic-workspace` **public** rather than privatize it, and to keep the kit's **Apache-2.0** license unchanged. The rows are kept, numbered, and struck rather than renumbered, because the plan and the baseline test refer to these numbers. What replaces them is not a settings change but a content rule: the planning and research documents stay out of the repository entirely, which `tests/repo-baseline.test.sh` enforces against both the working tree and the commits reachable from HEAD.
- Row 5 follows U7. Row 6 follows U13.
- Nothing in this repository automates these, with one narrow and tested exception. `tests/repo-baseline.test.sh` asserts that no committed shell script -- found by extension or by shebang, not just by a `.sh` suffix -- pushes, deletes or edits a release, or creates, edits, renames, archives, transfers, or deletes a repository, including through `gh api` with a mutating method. The exception is `scripts/release.sh --publish --confirm <document-id>@<n>`, added by U7: an ordinary release run prints the publish command as a finding and invokes nothing, which its own test asserts with a recording stub that counts zero invocations; the release is created only when the person running it names the tag, and the script refuses a mismatched name, a `CI` environment, a tag that already exists, and content whose commit is not an ancestor of the remote default branch. The baseline test allows exactly that script and the test that proves it, and each only while it still carries the refusal that makes it safe.

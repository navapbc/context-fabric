# Bring useful context into your next task

> Draft audience page for review.

You should not have to explain the same system landscape every time you start
a task, join a project or open an agent session. A maintained Context Fabric
view gives you a place to begin: the systems involved, where evidence lives,
and the limits of what is known.

## Crawl: start with the work in front of you

Read the [fictional organization view](../../views/meridian-health-agency/view.md)
to see the shape of the output. For real work, use a view whose sources and
maintainer are relevant to your task. You can read a view without installing
the framework or using an agent.

If you use an agent, supply the view's instruction and the relevant context.
When private machine bindings are needed, keep them in your own Individual
document. Shared views carry shared knowledge; your access settings stay yours.

If no useful view exists yet, draft an Org document from supported facts using
the entry guide. You do not need a team-wide rollout to begin. An Individual
document alone is not a substitute for the shared facts in an Org or view.

**[Choose your starting path](../../START-HERE.md).** Reading and drafting need
no framework installation. Validation and generation have their own
[dependencies](../dependencies.md). When shared upkeep becomes useful,
[bring your team in](teams.md).
